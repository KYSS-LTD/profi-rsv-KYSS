# V5 Tasks redesign

Страница «Задачи и мини-канбан» переделана под новую концепцию:

- вместо вытянутых Trello-колонок используется компактный dashboard;
- сверху: поиск, фильтры, дата, сброс;
- ниже: 4 KPI-карточки;
- слева: список задач с колонками source / AI confidence / status;
- справа: мини-канбан 2×2;
- действия по выбранной задаче: «В работу», «Готово», «Перенести срок», «Открыть карточку»;
- сохранены proof-элементы ТЗ: Telegram / Voice / Meeting, external kanban, confidence badge.
