# V4 design fix

Версия под стиль пользовательского SVG-макета:

- сохранен минималистичный стиль: белые карточки, stone-палитра, мягкие радиусы;
- кнопки и поля имеют одинаковую высоту `h-10`;
- кнопки не сжимаются и не съезжают;
- перенос срока вынесен в отдельную кнопку, чтобы не ломать карточку input-полем;
- kanban использует широкие колонки и горизонтальный скролл;
- карточки показывают source, confidence, AI-created и kanban provider;
- внешний kanban открывается отдельной ровной кнопкой.
